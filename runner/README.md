# Continuous Rust runner

The runner leases up to four jobs concurrently from the Go API and polls active schedule and Gmail triggers independently. Set `BACKEND_URL` (default `http://backend:8080`), the shared `RUNNER_TOKEN`, and optionally `RUNNER_ID`, `RUNNER_POLL_MS` (default 2000), `RUNNER_CONCURRENCY` (default 4, range 1–32), and `ALLOW_PRIVATE_HTTP` (default false). Keep private HTTP disabled unless workflows intentionally call trusted services on the local network.

Workflow mappings use `{{input.field}}` for the immediate parent node's output and `{{nodes.node_id.field}}` for any previously completed node. A string made entirely of one mapping retains its JSON type. `set_fields` merges configured fields into its input, `condition` follows its true or false port, and an HTTP node returns `{status,headers,body}`. Nonselected branches are recorded as skipped. Confirmed successful steps resume from saved output after a lost lease.

HTTP nodes resolve DNS before each request, reject private and reserved addresses by default, pin the resolved address for that request, ignore proxy environment variables, and do not follow redirects. GET and HEAD requests retry transient failures up to three attempts. Other methods retry only when `idempotency_key` resolves to a nonempty string; it is sent as `Idempotency-Key`. Use a distinct key per logical event, such as `{{input.id}}`. An interrupted non-idempotent request or Gmail send is marked uncertain for review. Rendered configuration and node output are limited to 256 KiB, with a mapping nesting limit of 32.

Gmail credentials use OAuth refresh tokens with `client_id`, `client_secret`, and `refresh_token`. The backend's Connect Gmail flow creates these credentials. Gmail triggers poll the Gmail history API with a configurable `query` (default `in:inbox`) and `poll_seconds` (minimum 30). The first poll establishes a history checkpoint; later polls page through every new-message history page, queue one event per matching message ID, and advance the checkpoint after all events are accepted. Messages deleted before they are fetched are skipped. The default inbox and unread queries filter Gmail labels directly. Other queries require a paginated matching-message lookup, currently limited to 10,000 messages; narrow the query if that limit is reached. If Google expires the history cursor, the runner reports an error and does not silently skip or replay mail. Publish a new workflow version to establish a new baseline after reviewing the data gap. Gmail send uses the Gmail API's `users.messages.send` endpoint. `GMAIL_TOKEN_URL` and `GMAIL_API_BASE` can redirect these calls in local integration tests. Live Google OAuth cannot be verified without a configured Google account and app.

Stop with SIGTERM or SIGINT. The runner stops claiming new jobs and gives active jobs up to 45 seconds to finish while heartbeats continue. A container health check can invoke `n9n-runner --healthcheck`; it requires recent job claims and trigger-list retrievals, or progress on active job and trigger work. Health timestamps are stored in `RUNNER_HEALTH_DIR` (default `/tmp/n9n-health`). Run tests with `cargo test`.
